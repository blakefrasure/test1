The objective is to build a real-time wait-time prediction engine for theme parks. The system must allow users to view current wait times and receive AI-generated 'best path' recommendations to minimize walking and wait times. Key features include: 1. User authentication and profile management. 2. A 'Park' entity that contains multiple 'Attractions'. 3. A 'WaitTimeHistory' table to store hourly data for AI training. 4. An API for mobile app integration. 5. Admin dashboard for park operators to manually override times. Performance is critical, as wait times refresh every 60 seconds.
